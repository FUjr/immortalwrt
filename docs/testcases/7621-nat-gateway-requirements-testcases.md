## 公共要求

1. 测试固件、配置和硬件拓扑必须记录版本、SHA-256、设备序列号和端口连接。
2. 破坏性、升级、攻击、容量和恢复出厂测试必须先备份配置并安排业务窗口。
3. PASS 必须保存命令输出、抓包、日志、截图或机器生成报告；只有源码或页面存在时标记 READY。
4. 每个用例执行后恢复临时账号、地址、路由、防火墙、SNMP、限速和测试服务。
